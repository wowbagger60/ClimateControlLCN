# ClimateControlLCN

Symcon-Module für die Klimasteuerung von LCN-Installationen: Sollwerte pro Raum, Raumthermostate, Läden und Dachfenster.

- [TemperatureControl](TemperatureControl/README.de.md): Raumthermostat mit Live-Sollwert, Auto-Knopf und Standard-Sollwerten in den LCN-Registern ([English](TemperatureControl/README.md))
- [TemperatureConfiguration](TemperatureConfiguration/README.de.md): Sollwerte für Heizen und Kühlen eines oder mehrerer Räume einstellen ([English](TemperatureConfiguration/README.md))
