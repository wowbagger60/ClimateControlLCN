# ClimateControlLCN

Symcon modules for the climate control of LCN installations: setpoints per room, room thermostats, shutters and roof windows.

- [TemperatureControl](TemperatureControl/README.md): room thermostat with live setpoint, Auto button and standard setpoints in the LCN registers ([Deutsch](TemperatureControl/README.de.md))
- [TemperatureConfiguration](TemperatureConfiguration/README.md): set the heating and cooling setpoints of one or more rooms ([Deutsch](TemperatureConfiguration/README.de.md))
